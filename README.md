# Portafolio Profesional - Desarrollo Fullstack II

## Descripción del Proyecto
Portafolio web personal e interactivo desarrollado como parte de la Evaluación Parcial N° 1 de la asignatura Desarrollo Fullstack II (DuocUC). El sitio web exhibe la identidad profesional del estudiante, su perfil en el área de ingeniería informática, habilidades técnicas y proyectos destacados[cite: 1]. Su diseño se inspira en la estética de terminal retro del sistema Pip-Boy de la saga Fallout, implementando navegación dinámica por pestañas, un mapa interactivo de ubicación y un formulario de contacto validado mediante JavaScript[cite: 1, 7].

## Tecnologías Utilizadas
* **HTML5 Semántico:** Estructura válida basada en etiquetas modernas (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)[cite: 1].
* **CSS3 Avanzado:** Estilos externos personalizados, uso de variables nativas, contenedores adaptables mediante CSS Grid y Flexbox, y diseño responsivo controlado por *media queries*[cite: 1].
* **JavaScript (Vanilla):** Lógica del lado del cliente para la navegación de pestañas y control de validaciones en el formulario de contacto con mensajes de error personalizados[cite: 1].
* **Control de Versiones y Despliegue:** Repositorio remoto en GitHub gestionado mediante *commits* progresivos y sitio desplegado públicamente en Vercel[cite: 1].

## Estructura de Archivos
* `index.html`: Documento principal con el contenido estructurado semánticamente.
* `style.css`: Hoja de estilos externa que define la interfaz visual, diseño responsivo y efectos visuales.
* `main.js`: Script encargado de la interactividad, control de secciones y validación del formulario.
* `img/`: Carpeta contenedora de los recursos gráficos e iconos del proyecto.
